# docs/REQUESTS.md

This file is the **cross-module request board**.

When your agent needs a change in another team member's module, or in a shared
file (`AGENTS.md`, `docs/`, `ui/`, `docker-compose.yml`, `scripts/`), do
**not** edit those files directly. Instead, add a request here.

Format each request as a new section:

```
## [OPEN] <short title>
- **Requested by:** <member>
- **Affects:** <file or module>
- **Why:** <one sentence>
- **Detail:** <what exactly needs to change>
- **Date:** YYYY-MM-DD
```

Change `[OPEN]` to `[DONE]` and add `- **Resolved by:** <PR link>` once
the owner has handled it.
